# Sistema-de-Gerenciamento-de-Horarios
Este sistema foi desenvolvido para auxiliar clínicas de estética no gerenciamento de agendamentos de clientes.  
O objetivo é oferecer uma solução local (sem necessidade de internet), simples de usar e visualmente agradável, 
permitindo que profissionais da clínica organizem seus horários e salas de atendimento de forma prática.

# Principais Features
- Tela de Login para autenticação dos profissionais da clínica.  
- Calendário mensal interativo para visualizar dias e horários disponíveis.  
- Agendamento de clientes com seleção de sala e serviço.  
- Tabela de horários mostrando agendamentos confirmados.  
- Interface estilizada com CSS e ícones para melhor experiência visual.  
- Persistência local dos dados de usuários, salas e agendamentos.

#  Tecnologias Utilizadas
- JavaFX → Interface gráfica moderna e responsiva.  
- Scene Builder → Criação visual das telas.  
- SQLite → Banco de dados leve e embutido.  
- JDBC → Conexão entre Java e SQLite.  
- CSS → Personalização da interface gráfica.  

# Objetivo
Fornecer uma aplicação desktop que permita:
- Melhor organização dos atendimentos.  
- Redução de conflitos de horários entre salas e profissionais.  
- Experiência simples e intuitiva para usuários iniciantes.
